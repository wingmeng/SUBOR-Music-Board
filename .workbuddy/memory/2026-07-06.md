# 2026-07-06 工作日志

## 记谱改善建议分析
- 从游戏音频工程师视角分析了 SUBOR Music Board 的简谱记谱系统
- 识别了当前系统的核心局限：固定时值（无延音线/附点）、音色固定、无力度控制、无噪声通道
- 提出了8项改善建议，按影响力×实现难度排列优先级矩阵
- 最高优先级：延音线(-)和噪声通道(CH4)——最急迫缺失+最低实现成本
- 中优先级：附点音符、方波占空比切换、力度标记
- 低优先级：音高滑动、音量包络、多级八度（当前±1已够FC范围）
