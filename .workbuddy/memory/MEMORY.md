# SUBOR Music Board 项目记忆

## 项目定位
- FC（红白机）风格三声部音乐板应用，使用简谱记谱
- 技术栈：Vue 3 + TypeScript + Vite，纯 Web Audio API 合成（无音频文件）
- NES 2A03 芯片音色模拟：方波(主旋律/和弦律) + 三角波(低频)

## 当前记谱语法
- 音符格式：`[#b]?[.,]?[1-7]` | `-`(延音线)，空格=休止符（八度修饰符 `.`/`、`,` 在数字**前**）
- 例：`.1`=高音do, `,1`=低音do, `#.1`=高音升do, `b,3`=低音降mi
- 延音线 `-`：延续前一个音符的时值，每格-增加一个八分音符时长
- 三声部数据：Column = [主旋律, 和弦律, 低频]，Score = Column[]
- 每格=八分音符（固定时值），延音线可扩展时值（无附点/连音线）
- 8个大调调号，6档BPM（60/75/90/105/120/135）
- 导出格式：.subor.json

## 输入交互（2026-08 起，已移除 INS/OVR 模式）
- 音符 1-7（含修饰符组合）或延音线 `-` → **覆盖**当前格，后续不动，光标右移
- 空格 → **插入**当前格（同声部右移，末位丢弃），光标右移
- Backspace → 删除前一格 + 左移填补，末位补空格，光标左移
- Delete → 清空当前格，不动
- 判断只看输入字符类型（空格=插入，其余=覆盖），与格子是否为空无关

## 音频引擎特点
- MusicEngine 单例，OscillatorNode → GainNode → DynamicsCompressorNode → destination
- 声部八度分层：OCTAVE_MULTIPLIERS = [2, 1, 0.5]
- 方波断奏包络（线性淡出），三角波 1ms attack + 3ms fade + 2.5x增益补偿
- Sequencer 预调度模式：逐声部扫描，延音线合并为单个长振荡器
- 孤立延音线（开头/休止符后）视为休止符，不调度
- 支持 playback 中实时变速变调（stopFrom 选择性停止）

## 协作约定
- 帮助弹窗（HelpDialog.vue）的文案由用户本人撰写；AI 只做**事实准确性把关**（输入规则/快捷键/语法说明需与代码 `types.ts`、`useNotation`、`NotationGrid` 行为一致）。
- 配色偏好：帮助图标与帮助弹窗统一用帮助图标的绿色 `#9fc`，不引入多色系；红色 `#c33` 仅保留给报错/板体外框语义。
- 帮助弹窗无底部确认按钮，关闭方式：右上角 ×、点击遮罩、按 Esc。
