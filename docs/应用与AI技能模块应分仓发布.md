## 决策场景
当一个项目包含前端/应用主体与独立AI技能模块时，是否应拆分为两个仓库

## 决策内容
优先拆分为两个独立仓库：
- SUBOR-Music-Board（应用端）专注 UI、交互、核心类型定义与运行时
- SUBOR-music-generator-skill（AI技能）专注提示词工程、模型调用、输出格式化
- 二者通过 README 文档链接建立弱耦合，不共享代码路径

## 适用范围
所有「应用主体 + 可插拔AI技能」架构的开源项目
