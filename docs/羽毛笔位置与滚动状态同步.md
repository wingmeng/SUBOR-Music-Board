修复羽毛笔位置未与滚动同步的问题：滚动乐谱区域时，羽毛笔停在旧坐标（其定位基于相对 `.board-body` 的 absolute 坐标，而滚动发生在内部的 `.board-scroll`），不会跟随上次编辑的文本框。

方案：在 NotationGrid 中监听滚动容器（`gridRef.parentElement`，即 `.board-scroll`）的 `scroll` 事件，用 requestAnimationFrame 节流后重新吸附羽毛笔到当前焦点 input：

- 文本框仍在滚动视口内（rect 与容器视口有交集）→ `quill.moveTo(el)` 跟随；
- 文本框滚出视口 / 焦点不在网格 → `quill.setVisible(false)` 隐藏（避免笔画到板框外）；
- 播放中（docked）跳过，羽毛笔固定于墨水瓶。

配套改动：`useQuill.ts` 增加 `visible` ref 与 `setVisible`；`Quill.vue` 增加 `visible` prop（非 docked 且不可见时 `display:none`）；`App.vue` 传入 `:visible="quill.visible.value"`；`updateQuillPosition` 统一管理可见性（INPUT 显示、非 INPUT 隐藏）。

附带收益：输入越过末尾时浏览器自动将新格滚入视口 → scroll 事件触发 → 羽毛笔自动跟随新格。

行为验证：`vue-tsc -b` 通过；`vite build --outDir dist-verify` 通过（`pnpm build` 清空 `dist/` 仍被沙箱 safe-delete 拦截，环境问题与代码无关）。

已知取舍：滚动跟随沿用 Quill 的 left/top 0.2s 过渡，快速滚动时羽毛笔呈平滑追赶（可接受，若需精准可临时禁用过渡）。
