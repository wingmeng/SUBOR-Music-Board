项目代码风格约定：

**Vue 模板规范**
- 标签属性如有多个，一行一个，便于阅读和 diff

**条件语句规范**
- if 代码块即使只有一行，也不能省略大括号，保证代码可扩展性和一致性

**其他约定**
- 参考业界最佳实践（如 ESLint + Prettier 标准配置）
- TypeScript 严格模式
- 组件使用 `<script setup lang="ts">` 语法
