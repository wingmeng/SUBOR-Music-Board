# 撤销/重做功能实现规范

## 背景

编辑过程中经常出现误删（误覆盖、误 Backspace / Delete、误 CLEAR 清空），需要一个快捷键恢复上一次修改。采用 **快照栈（undo/redo）** 方案，在数据层实现，视图层只需接快捷键。

## 实现位置

- 核心逻辑：`src/composables/useNotation.ts`（快照栈 + undo/redo）
- 快捷键与聚焦收尾：`src/App.vue`（onGlobalKeydown）
- 输入取消与聚焦能力：`src/components/NotationGrid.vue`（cancelPendingInput / focusCell）

## 快照粒度与覆盖范围

- 快照 = 修改前的**完整乐谱深拷贝 + 光标位置**（`{ score: Column[], cursor: { col, voice } }`）。
- 在以下每个内容修改入口的**修改前**记录一次快照（一次调用 = 一个撤销单元）：
  - `setNote`（音符覆盖）
  - `clearNote`（Delete 清空经由此处，避免重复快照）
  - `insertNoteAt`（空格 / 延音线插入，右移）
  - `backspaceAt`（退格删除，左移填补）
  - `resetScore`（CLEAR 清空整个乐谱）
  - `loadScore`（OPEN 导入，覆盖原乐谱）
- 因此 **CLEAR 清空、导入覆盖** 同样可撤销，覆盖全部"误删"路径。
- 撤销栈上限 100 条（`MAX_UNDO_DEPTH`），超出丢弃最旧快照；重做栈随撤销/重做自然增减，新修改时清空重做栈。

## 不进入撤销历史的内容变更

- `moveCursor` 的纯列扩展（向末尾方向导航时补空白列）：属于光标移动的副作用，非内容修改。
- `syncColumns` 的列数对齐（补齐铺满 / 裁空白尾 / 保留含内容列）：由窗口可视容量驱动，不应被撤销。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl`/`Cmd` + `Z` | 撤销 |
| `Ctrl`/`Cmd` + `Shift` + `Z` 或 `Ctrl`/`Cmd` + `Y` | 重做 |

- 在 `App.vue` 的 `onGlobalKeydown` 的 Ctrl/Cmd 分支处理，与 OPEN / SAVE 一致：**播放中禁用**、**任意对话框打开时禁用**。
- `e.preventDefault()` 阻止浏览器默认的文本框撤销行为。
- 事件冒泡顺序：NotationGrid 的 document keydown 先执行，但其对 Ctrl+Z 不匹配任何分支（音符输入分支要求无修饰键），不会拦截。

## 撤销/重做后的收尾

1. **取消待处理输入**：调用 `NotationGrid.cancelPendingInput()` —— 清掉长按重复定时器、待决升降号/八度修饰符、动画输入队列，并置 `inputCancelled` 标志；若书写动画随后结束，`handleQuillAnimationEnd` 检测到该标志后直接返回，不落盘队列数据、不推进光标（防止撤销结果被残留输入"抵消"）。
2. **列数对齐**：恢复的乐谱列数与当前可视容量可能不一致，调用 `syncColumns(visibleColumns)` 补齐铺满 / 保留含内容列滚动。
3. **聚焦光标**：`nextTick` 后调用 `NotationGrid.focusCell(cursor.col, cursor.voice)`，DOM 焦点与羽毛笔跟随恢复后的光标（`focusCell` 内部置 `suppressSeekOnFocus`，不会移动暂停态的播放恢复点）。

## 已知取舍

- 快速连续输入（动画队列批量写入）时，每个字符各占一个撤销单元：连续输入 N 个音后需按 N 次 Ctrl+Z 逐步退回。符合"每步输入 = 一步撤销"的直觉，未做批次合并。
- 撤销不区分声部/操作类型，统一回退整个乐谱到修改前状态。
