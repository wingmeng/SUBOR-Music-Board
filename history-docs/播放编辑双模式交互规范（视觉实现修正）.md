播放/编辑双模式交互规范更新：
- 播放禁用时仅通过 `pointer-events: none` 禁用交互，**禁止添加 opacity 半透明效果**，确保视觉质量不受影响
- 墨水瓶图标必须严格置于 Board 组件内部右下角（非全局右下角），使用 `position: absolute; right: 6px; bottom: 6px` 定位，**不得超出 Board 边界**
- 墨水瓶样式以 `demos/墨水瓶.html` 为唯一参考，采用 CSS 伪元素（::before/::after）+ linear-gradient 实现，含瓶口三角、瓶颈阴影、青色瓶身（#3cc）及白色 'INK' 标签
