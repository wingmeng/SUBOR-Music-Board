## 记谱系统改造决策（2026-05-21，第二次更新）

### 当前方案
项目使用混合记谱：a-g=中音, A-G=中音升号, 1-7=低音, 空格=休止符。每个cell单字符，maxlength=1。

### 改造方向（已确认）
综合方案：**输入存双字符，显示用CSS伪元素画点**

#### 数据层（存储）
- 采用方案A：双字符cell（maxlength 2-3），用后缀区分八度
- `1'` = 高音do（对应简谱上加点）
- `1` = 中音do（不加点）
- `1,` = 低音do（对应简谱下加点）
- 升降号用前缀：`#1'`（高音升do）、`b3,`（低音降mi）
- 数据自包含，每个cell存完整字符串，如 `"1'"` `"3,"` `"#4'"`

#### 渲染层（显示）
- 输入框内只显示数字部分（如 `1`）
- 用CSS `::before` / `::after` 伪元素渲染上下加点
- 检测存储值末尾字符：`'` → 上加点，`,` → 下加点
- 参考 demo: `demos/高音低音.html`
- `.s1` 一个上加点（高音）、`.s2` 两个上加点（倍高音）
- `.s-1` 一个下加点（低音）、`.s-2` 两个下加点（倍低音）
- 注意：`.tone` 需 `display: inline-block` + `position: relative` 确保伪元素定位正确
- `Press Start 2P` 字体下需微调 `top`/`bottom` 偏移量

### 新增功能（已确认）
添加调号/定调设置（如 1=C, 1=G, 1=F 等），使简谱从相对唱名转为绝对音高：
- 播放时根据调号将 1-7 映射到具体音高
- 显示和输入不受调号影响（仍然是 1-7 相对数字）
- 只影响最终发音的绝对频率
