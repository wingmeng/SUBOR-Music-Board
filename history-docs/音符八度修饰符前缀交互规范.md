项目音符输入核心交互规范（已实现）：
- 高音修饰符使用句号 `.` 键，作为前缀输入，显示为数字上方的点；
- 低音修饰符使用逗号 `,` 键，作为前缀输入，显示为数字下方的点；
- 升降号 `#`（升）和 `b`（降）同样作为前缀输入；
- 所有修饰符（. / , / # / b）必须在数字前输入，光标全程保持不动，不发生回跳或位置切换；
- 用户输入修饰符后存入 pending 状态，光标留在当前格；
- 用户输入数字 1-7 时，自动拼合 pending 状态完整发射，光标前进到下一格；
- `.` 和 `,` 键位相邻且视觉位置对应（右排键→上点，左排键→下点），强化直觉操作；
- 升降号用独立 .acc span 在 input 左侧显示（未聚焦时），聚焦时 input 显示完整值。
